# Academia André - Sistema de Gestão

## 📋 Sobre o Projeto

Este projeto é um sistema de gestão desenvolvido em **Java** que aborda a comparação e análise entre academias de **grande porte** e **pequeno porte**, explorando as diferenças operacionais, tecnológicas e gerenciais entre esses dois modelos de negócio.

## 🎯 Objetivos

- Demonstrar as características estruturais de academias grandes vs. pequenas
- Implementar funcionalidades de gestão adaptadas para diferentes escalas
- Analisar eficiência operacional em contextos variados
- Fornecer insights sobre modelos de negócio fitness

## 📊 Comparação: Academias de Grande Porte x Pequeno Porte

### Academias de Grande Porte
- ✅ Múltiplas filiais/unidades
- ✅ Equipe de gerenciamento estruturada
- ✅ Sistemas de TI complexos e integrados
- ✅ Múltiplas modalidades de treino
- ✅ Infraestrutura robusta
- ✅ Atendimento especializado (personal, nutrição, fisioterapia)

### Academias de Pequeno Porte
- ✅ Operação simples e centralizada
- ✅ Equipe reduzida e versátil
- ✅ Menor complexidade tecnológica
- ✅ Modalidades selecionadas
- ✅ Custo operacional menor
- ✅ Relacionamento mais próximo com clientes

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: Java
- **Padrões de Design**: Orientação a Objetos
- **Funcionalidades**: Gestão de membros, agendamento, pagamentos, controle de acesso

## 🚀 Como Executar

### Pré-requisitos
- Java 11 ou superior
- Maven ou Gradle (conforme configurado)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/dimitriusgabineski/academia-andre.git

# Navegue até o diretório
cd academia-andre

# Compile o projeto
mvn clean compile
# ou
gradle build

# Execute
mvn exec:java
# ou
gradle run
```

## 📚 Funcionalidades Principais

### Gestão de Membros
- Cadastro e atualização de informações de alunos
- Histórico de adesões e cancelamentos
- Perfil de treino e objetivos

### Controle de Assinaturas
- Planos diferenciados por porte
- Pagamentos e recibos
- Renovação automática de mensalidades

### Agendamento
- Reserva de aulas coletivas
- Agendamento com personal trainer
- Gerenciamento de horários

### Relatórios e Análises
- Comparação de lucratividade por porte
- Taxa de retenção de membros
- Análise de ocupação de espaço

## 💡 Insights: Grandes vs. Pequenas Academias

| Aspecto | Grande Porte | Pequeno Porte |
|---------|-------------|--------------|
| **Custo Inicial** | Alto | Baixo |
| **Escalabilidade** | Fácil | Limitada |
| **ROI** | Médio-Longo Prazo | Curto Prazo |
| **Automatização** | Alta | Baixa |
| **Satisfação do Cliente** | Variável | Frequentemente Alta |
| **Custo por Aluno** | Menor | Maior |
